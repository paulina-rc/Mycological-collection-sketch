# Mycological collection - design proposal

A visual prototype (only HTML y CSS, without backend) of the mycological collection system for the UNED (CITTED)

- `index.html`: page with all the pages 
- Screens of the QR : `qr-profile.html`, `record-not-available.html`, `selection.html`.
- Internal system: `login.html`, `specimens.html`, `detail.html`, `record.html`, `label.html`.
- `capturas/`: image of each page

> [!IMPORTANT]
>  all scientific data, properties, dates, and coordinates are only examples for the desing proposal
